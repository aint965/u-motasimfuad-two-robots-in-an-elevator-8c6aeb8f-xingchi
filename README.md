Entry for the [Two Robots in an Elevator](https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f) competition on make.fun.

The program (`main.ts`) writes a single line of awkward small talk that one robot says to another while they ride an elevator together — a robot that already knows far too much about its fellow passenger — to `/output/entry.txt`.
